# ClinicQ

A queue and waiting-time system for small walk-in clinics in Sri Lanka.
Patients join from their phone using a link or QR code and see their live position and estimated wait.

## Layout
- `apps/web`: Next.js front end. Patient pages (join, track) and staff pages (queue, history) *(planned)*
- `apps/api`: Node.js/TypeScript back end (modular monolith) and SMS background job *(planned)*
- `docs`: requirements, plan, architecture and design decisions
